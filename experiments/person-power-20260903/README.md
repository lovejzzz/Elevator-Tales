# 人物直接耗电实验 · 2026-09-03

结论：建议以 **初始 60 电／容量 72、电梯每站 1 电、充电每电 1 金币** 作为下一版候选。多数人物每站耗 1 电，游客、教练耗 2 电；幽灵保留 0 电。不是只把原电池数字放大：充电价格和检查员规则必须一起适配。

这是隔离的程序实验，不是已发布版本。当前生产 `lib/` 的 10 个 TypeScript 文件与实验前逐字一致，公开 v6.7 未更新。实验文件没有改写此前 checkpoint。

## 建议参数

| 项目 | 本轮候选 |
| --- | --- |
| 初始电量／容量 | 60／72 |
| 电梯运转 | 1 电／站，空驶也消耗 |
| 普通人物 | 1 电／人／站 |
| 游客、教练 | 2 电／人／站 |
| 幽灵 | 0 电；仍有延误邻座等代价 |
| 神秘人、百变人 | 当前属性为 1–2 电，按各自出现／变身规则刷新 |
| 复制人 | 未复制耗电时为 1；复制后使用来源的当前耗电，不递归复制 |
| 充电价格 | 1 金币＝1 电，保留每 10 层商店 |
| 稳压模块 | 每站抵消 1 点人物耗电，限装一次 |
| 其他节能 | 维修工、幽灵配对、节能线路触发时共享每站 1 电抵消上限 |
| 节能底线 | 最多抵消人物耗电，不能抵消电梯运转，更不能变成回充 |
| 检查员 | 偶数层检查：本次总耗电 ≤4 则 +1 金币；否则躁动 +1，高躁动倍率仍适用 |

公式：每站总耗电＝1＋车内人物耗电之和−实际生效的节能。实际节能不能超过人物耗电之和。

例：3 位耗电 1 的人物和 1 位耗电 2 的人物，生效节能 1，本站消耗 `1＋3＋2−1＝5` 电。送达这一站仍收费；属性变化后的耗电用于下一次出发。

仿真的主要购物策略是先补至 **62 电**，钱不足则按可负担数量补电，再考虑升级；另测了补至 48、54 和充满容量。这是机器人策略参数，不代表玩家必须购买固定电量，亦不应在界面中承诺“62 电保证到下一商店”。

容量 66–72 都是可行范围。72 留出额外付费储备空间；本轮没有证据证明它是唯一最优值。

## 测试规模与证据

共 **16,700 局策略模拟、1,530,335 次楼层推进**，不含 18 局启动冒烟测试；另有 **18,096 个状态校验用例**、3 个充电用例、2 个商店电量边界用例。全部已完成，没有对局撞到 600 层保护性截断。

| 阶段 | 局数 | 目的 |
| --- | ---: | --- |
| screen | 3,300 | 对照原版、初始电量、容量和充电价格 |
| refine | 3,200 | 检查员阈值及充电策略细化 |
| holdout | 3,800 | 新种子复测，以及固定初始 60 的容量对比 |
| ablation | 3,360 | 运转 0／1／2、节能上限 1／2／3、幽灵耗电与禁用节能 |
| contexts | 540 | 缺钱、高躁动、后期成型局面 |
| final | 2,500 | 定稿候选，10 种策略各 250 局，使用新的种子批次 |

所有模拟的预报断言均通过。独立状态校验覆盖 21 类人物、6 个站位、楼层奇偶和触发周期、高低躁动、升级组合，以及 6,000 个随机车厢；独立重算人物耗电、复制来源、抵消上限，再核对预报与实际扣电，也核对检查员奖励／处罚。0 个不一致。

## 为什么不只增加初始电量

首轮同一批种子、同一组测试策略，每行综合搭配策略 60 局。除旧版外均使用新人物耗电、原检查员条件。

| 初始／容量 | 充电单价 | 综合搭配平均失败楼层 | 解释 |
| --- | ---: | ---: | --- |
| 原版 20／24 | 3 | 119.32 | 旧人物耗电作基线，不代表真人水平 |
| 新制 20／24 | 3 | 12.07 | 直接换公式但不配套调数值不可行 |
| 40／48 | 1 | 79.42 | 少人策略 90.45，高于综合搭配；对多人组合偏苛刻 |
| 50／60 | 1 | 112.73 | 开始可行，但偏音乐家策略只有 103.68 |
| 60／72 | 1 | 123.00 | 多人搭配恢复可行性 |
| 70／84 | 1 | 121.60 | 对高级策略没有稳定增益，主要放宽前段容错 |
| 60／72 | 2 | 94.97 | 经济明显收紧 |
| 60／72 | 3 | 52.45 | 平均仅载 2.07 人；本批综合搭配策略没有购买任何升级 |

最后一行每局平均收入 430.38，充电支出 336.55，约占收入 78%。这不仅是续航问题，而是收入被电费挤占，促使策略减少接人。

## 独立定稿复测

候选 `inspect3`，每个策略 250 局。表中“平均楼层”是最终绝对楼层，不是通关率，也不是玩家预期水平。

| 策略 | 平均楼层 | 平均在车人数 | 耗尽电量失败／250 |
| --- | ---: | ---: | ---: |
| 综合搭配，补至 62 | 116.32 | 3.75 | 3 |
| 综合搭配，每次充满 72 | 118.64 | 3.79 | 0 |
| 偏护士控场 | 117.65 | 3.55 | 4 |
| 偏维修工 | 116.12 | 3.78 | 2 |
| 偏音乐家控场 | 113.50 | 3.69 | 5 |
| 只接耗电 ≤1 的人物 | 112.15 | 2.85 | 0 |
| 偏幽灵／驱魔师 | 111.30 | 3.87 | 3 |
| 不用任何节能来源 | 109.51 | 3.50 | 10 |
| 最多 2 位乘客 | 90.13 | 1.45 | 0 |
| 贪心接满 | 12.00 | 5.43 | 223 |

“不用节能”同时排除了维修工、驱魔师，以及稳压、节能线路升级，是组合禁用实验，不是对某一个角色的纯因果估计。偏某类人物的策略仍会接其他乘客，不是纯单人物队伍。

综合搭配策略每局平均充电支出 500.19，约占收入 **23.62%**；升级支出 868.80。到前 3 个商店时，约 **49.73%** 的记录只剩 0–5 电；首次到商店平均剩 5.98 电。因此，电量不是无关紧要，只是谨慎策略常能用取舍避免断电，最终多败于躁动。

充满策略比综合搭配高 2.32 层，配对 bootstrap 描述性 95% 区间为 `[-0.73, 5.56]`，不能宣称存在确定优势。偏护士、偏维修工也没有被显著甩开。本轮未发现简单节能堆叠碾压其他策略，但不能据此证明全局不存在最优套路。

## 单项对比与角色风险

- **电梯运转 2 电过于惩罚多人。** 同批消融种子下，综合搭配从 117.71 降至 92.83；低耗电策略为 98.51。运转 0 电的综合搭配为 120.40，不能说已经出现无限空转：完全空车对照仍在 28 层因躁动失败。选择 1 电是保留明确的运转成本，并避免 2 电对搭配的挤压。
- **节能无需增加叠加复杂度。** 共享上限 1／2／3 时，综合搭配均值 117.71／116.39／116.28，未见稳定收益；不解释为“多节能有害”，小差异可能来自策略路径与随机波动。
- **容量不是越大越好。** 固定初始 60、单价 1，充满策略在容量 60／66／72／84 下为 117.30／118.51／121.08／116.75（各 80 局）。这是小样本策略结果，不是 72 的精确最优证明。补至 62 的策略在容量 ≥66 时轨迹一致，因为它不使用更多容量，不能将这些重复轨迹当作额外独立证据。
- **幽灵 0 电暂可保留。** 偏幽灵策略未领先；综合搭配对幽灵的接取率为 18.18%，不是无脑必拿。改为耗电 1 的消融也没有显示必须改动的稳定理由。
- **检查员需要新条件。** 原来要求抵消后人物耗电为 0，在人人耗电后很难实现。测试了人物净耗电上限 0／2／3／4，对应运转 1 时总耗电上限 1／3／4／5。建议总耗电 ≤4；独立定稿中接取率 17.23%，仍是条件型人物，不是可靠万金油。
- **高耗电人物没有失去价值。** 综合搭配对游客接取率 37.27%、教练 56.01%；动态人物神秘人 34.27%、百变人 28.90%、复制人 29.92%。所有 21 类都实际被接取及送达。接取率受解锁楼层、候选分布和策略偏好影响，不能直接作为人物强度排名。

## 不同困境没有相同赢家

每个情境 3 策略各 60 局；它们是人为构造的条件起点，不可并入正常开局概率。41 层起点电量 60，81 层起点电量 62；原有金币、躁动和升级按固定 fixture 设置。

| 起点 | 综合搭配最终楼层 | 低耗电 | 偏音乐家 |
| --- | ---: | ---: | ---: |
| 41 层、0 金币、躁动 3 | 79.85 | 84.45 | 81.62 |
| 41 层、120 金币、躁动 12 | 89.23 | 80.82 | 85.72 |
| 81 层、150 金币、已有控场／节能升级 | 108.08 | 109.75 | 106.62 |

## 尚未解决／不能推断

1. 机器人具备固定评分、站位搜索及短程预测，不能将 116 层解释为普通玩家成绩，更不能单凭模拟证明“最好玩”。贪心接满只有平均 12 层，真人是否觉得反馈公平，需要后续界面与上手测试。
2. 现有默契契约在综合搭配的 250 局中有 246 局被购买。它仍是控场主轴；本轮没有重新解决这张卡的全局依赖问题，不应宣称整个游戏平衡已经定稿。
3. 本轮没有修改金币回报、躁动曲线、人物关系及升级价格。除了新耗电、充电及检查员适配，其他机制保持 checkpoint。界面文字仍是生产版的“额外耗电”，实验拷贝并非可直接发布成品。
4. 下一版落地时需同步改人物卡、总耗电拆解、商店价格、检查员说明、动态人物文案，并测旧存档 20／24 向新制迁移；本轮不发布，也没有做浏览器验证。
