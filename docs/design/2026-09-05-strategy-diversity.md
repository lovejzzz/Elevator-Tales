# 策略多样性验收约定

用户设计要求：没有绝对强势或明显弱势的成熟玩法，每种策略有自己的美感。状态、人物与能力让玩家自行发现关系；不在界面公布流派名称或配方。

## 要保住什么

- **允许局部很强，不允许无条件通吃。** 玩家经营出一个短暂的强势窗口应当痛快。平衡针对进入条件、持续成本、占位和退出时机，不把每次爆发磨平。
- **不同玩法拥有不同的乐趣。** 低躁动的美感可以是精确安排工作与到站；高躁动是算准承受与兑现窗口；中躁动应有值得主动维持的理由，不只是途经地带。这是待验证的设计目标，不是对现状的验收。
- **坏处是关系性的。** 躁动降低不自动等于改进；护理也不等于所有人物都受益。比较时保留工作、状态加价、暂存收入及失去的机会，不用“金币减躁动”的单一分数宣布优劣。
- **不保证任意乱搭都一样好。** 学会配合、看懂局面应提高表现；检验的是有合理经营逻辑的选择是否拥有真实、可遇到的适用场景。
- **不能靠针对玩家的惩罚制造平衡。** 不根据强弱暗调候客，不用动态涨价、强制死亡楼层或额外拒载罚金掩盖无意义的角色。

## 每个值得保留的玩法必须回答

1. 它让玩家在哪个具体时刻觉得“我发现了秘密”？收益必须在结算或状态反馈中看得见。
2. 它放弃了什么：现金、电量余地、座位、唯一挪动、安装位，还是其他状态的收益？
3. 在什么正常可遇到的局面下，另一种经营方法更合理？不能只靠极端倒霉或专门克制事件。
4. 缺少一个关键角色时是否仍能过渡？启动需求是否被人物解锁与候客供给实际支持？
5. 成型后是否仍需判断送达、换人、控制与投资？若只剩重复相同操作，应检查持续回报结构，而不只削弱启动收入。

## 检验次序

1. **先校验测试者。** 关门方式与购物方式分开；记录实际购买和奖励曝光。未购买某能力的测试者不能验证该能力平衡。研究代理不是玩法本身。
2. **局面内比较，再跨局统计。** 从真实轨迹保存公开状态，比较合法替代行动的资源、工作与兑现窗口；固定随机分支做回放诊断，但不把实际未来交给决策者。明显优劣是局部结论，不直接上升为全局统治。
3. **保留反例。** 每个强项都寻找常见的代价或更佳替代；每个低采用角色都寻找可遇到的独特贡献。未找到反例是待调查，不是证明不存在。
4. **观察分布而非一个均值。** 分开记录前期启动失败、每十层余量、成熟后的现金积累、超过60层的尾部、角色/升级曝光和实际收益。比较时列出样本数、种子是否见过、截尾和测试者局限。
5. **修正后用新种子和完整实玩复核。** 不用脚本胜率代替紧张感、清晰度与25–40分钟节奏；实玩同时记录“为何选择”和“为何死亡”。浏览器从启动起强制静音，音乐与音效均关闭。

## v8.32 当前证据与优先级

### 维修工：先验证价值窗口，再决定删除或增强

960次固定行动执行（320局面，各比较不接/普通/高危）找到条件性强势，而非无条件优势。起始3躁动、维修工三站、醉汉两站且相邻：高危维修工推动醉汉在高档到站，组合收入16→30、同耗电、两人安全；其中4币来自高危自身、10币来自醉汉状态加价。起始7躁动高危版立即失控，普通版仍有安全窗口。两者都是构造场景，不是自然出现率或人类胜率。

低档工作也有时序区别：高危维修工从0或1躁动起步可连续两次低档关门；从2起步会暂停，护士能提供另一种完成机会。音乐家推向中档，不能当作护士的等价替代。因此保留高危版本，不用删除缺点或统一加收益来制造“平衡”。

下一项验收是这些局面能否在正常候客与旅程中遇到，以及玩家能否读懂关门快照、工作暂停和到站加价。固定红线由任一方触发，必须在双方卡片说明；发现组合可以有惊喜，隐藏必要代价不属于我们要的秘密。

### 最新补充：验收不等于把平均值拉平

- 每种成熟打法都要保存至少一个正常可遇到的强势局面，以及一个换打法更合理的反例；记录启动、维持、兑现、退出，不能只给一个综合分。
- 商店与人物一起比较：同一固定购买顺序只能检验该测试者，不能代表所有成型组合。需要实际购买、触发机会、未触发损失与替代安装位的证据。
- 优先处理“无条件划算”和“没有使用场景”；保留有门槛的爆发。低档的精确经营、中档的节奏衔接、高档的冒险兑现是研究方向，不是游戏内流派标签，更不是已经证明平衡。
- 修测试器也属于平衡验收：2026-09-05礼宾实验的旧基线复现门槛失败，36条中32条完全一致，4条在相同状态下选择不同动作。原因是规划随机种子包含炸弹说明文案。planning-v2排除名称、说明、版本与历史账单，仅从公开机械状态生成想象种子；文案变化不再意外换决策。38项Lab回归通过。
- 本轮礼宾“中档+3”仍是隔离实验，游戏默认仍为新乘客固定+2。72条旧规划器执行封存，不作为本轮采纳依据；新规划器对照必须两边重新执行。旧固定动作能重放，不等于旧决策会重现，两类证据严格分开。

### 较早的投资诊断（非当前版本验收）

最新48条planning-v2购物对照补充：机会记忆测试者实际选出了不含礼宾／稳压、仍F120存活535币的默契／并联／小费盒／计价器组合。因此“通用两件套必需”没有成立，后期经济问题必须跨组合看。该测试者也有固定组120存活、改购物后22躁动失败的反例，不是新万能顺序。中档礼宾+3／40币在处理组34次店内出现但0购买，观察层上升不能归给中档收益。默认不采纳该实验；扩容／加急的低采用仍受模型估值缺失影响，不能宣布弱势。完整证据见研究工作区`player-lab/V832-ADAPTIVE-SHOPPING.md`与相应逐店估值。

20条新的“当前乘客用电约束下投资”开发轨迹，与30条已有默认轨迹比较，未改游戏数值。相同规划关门方式下，相比只留运转预算的投资，30层前结束从7/10降至1/10，中位观察层从28升至39；仍有119层断电、494金币的同一条长局。不能宣布投资玩法已平衡。

规划/危险窗口两组各10条，使用相同新购物方式。坏人暂存实际兑现分别14/101金币，高躁动醉汉加价30/110金币；上行次数500/413不同。这说明测试覆盖不同状态收益，不说明两种玩法的乐趣或强度相等。后者平均观察层反而从默认44.3变成42.3；新购物方式不是普遍改进。

快递员与幽灵在两组中都常被采用：检查是否变成所有玩法的必需骨架，而不是仅因常选就削弱。检查员、音乐家、神秘人低采用：下一步查具体错失机会、到站时间、状态要求和替代人物，而不是直接删除。中躁动的独立经营价值仍待审查。
