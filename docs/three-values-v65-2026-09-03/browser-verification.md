# 浏览器操作验证

日期：2026-09-03。本地开发页面，隔离 Chromium 会话，视口 1440×900、390×844、320×568。手机尺寸为浏览器模拟，不是实体 iPhone/Safari 测试。

使用仅在浏览器测试上下文存在的状态夹具建立边界局面，再通过页面真实点击进行上客、上楼、购买、补电和重新开始。夹具不是发布代码或玩家后门。

- 儿童单独站在第 2 格：下一站人物躁动 +1。把护士放到相邻格后立即变成不变，护士显示 −1。实际上楼从 15 到 16 层，电量 20→19、躁动 6→5，与预报一致。
- 断电：电量 2、游客在车内，真实出发后电量归零；显示醒目的「本班失败」和断电原因。390×844 下失败弹窗可完整显示。
- 躁动：16 层躁动 14，真实出发后到 17 层躁动 18，显示躁动失控原因。320×568 下重新开始按钮可见、可点；重开电量为 20。
- 商店：10 层、电量 2、金币 200，购买稳压模块花 45，再补 20 电花 60，得到金币 95、电量 22。升级清单正确显示已安装模块和六个站位。
- 320×568 商店最后实测内容高度 481、滚动高度 481；离开按钮位于 y=461–513，无需滚屏操作。
- 21 类基础人物卡在 320×568 下逐组检查，卡片高度与滚动高度一致，未裁掉关键关系文字。动态人物另有机制随机回归，但此项布局遍历不等于所有可能随机偏好字符串的穷举。
- 390×844 最长规则组（幽灵、醉汉、复制人）最后实测卡片 336/336 像素，卡面完整；高躁动的 +2/+4 同步显示。
- 修复极矮屏幕车内头像缩为 0 的问题；320×568 下实测头像 24×24，保持正方形比例。该极小视口优先保留完整卡片规则，候客头像隐藏，车内头像仍保留。
- 桌面最终页面正常渲染，参数仅电量、躁动、可用金币；失败、手机卡面、商店最终截图已人工检查。
- 最后浏览器 errors 查询没有未捕获页面错误。开发热更新中曾出现 renderer 提示，未导致页面崩溃；不据此宣称不存在任何控制台警告。
