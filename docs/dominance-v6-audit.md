# Elevator Tales v6：优势打法与漏洞专项测试

## 结论：本轮不能判为“没有碾压套路”

未找到某一种固定人物组合在全部测试局面都最强，但找到了一条明显偏强、会绕开人物互动的宏观路线：前期经营赚钱，后期大量空车上行，把存款直接兑换成楼层纪录。

同时发现炸弹客的一个确定性结算漏洞。当前版本不宜给出“人物制约已充分平衡”的结论。本轮只新增测试和报告，没有修改线上规则或部署。

## 测试设计

1. 训练筛选：33 种预设策略/参数组合各 100 局，再对空驶假设补测 4 种策略各 100 局，共 3,700 局。
2. 独立验证：12 种代表策略各 300 局，再用同批新种子验证 80 层停接与持续载客两个对照，共 4,200 局。
3. 条件压力测试：6 种策略 × 4 类开局 × 100 局，共 2,400 局。
4. 总计 10,300 局、1,459,351 次上行结算；躁动范围和电量变化未发现预测越界。没有对局触及 600 层观察上限。
5. 另测 2,000 组复制人反复换位、复制人相邻，以及引信/耐心结算优先级。

策略覆盖：1/2/3/4/6 人搭载、保守/激进风险偏好、恋人、小偷警察、不受控小偷、幽灵驱魔师、安抚角色、高车费、百变人、复制人、教练、快递短途、安全角色限定、分阶段经营、不同买卡路线，以及三站前瞻策略。共有 37 种策略/参数配置，不是 37 个同样智能或穷尽所有可能的玩家。

训练、验证、压力测试使用不同种子组。按楼层/阶段独立播种，避免一次不同操作改变整条后续随机序列；恋人召唤仍取决于车内状态，不能视为完全相同候客轨迹。主验证从 1 层正常开局、不使用固定恋人教学阵容。

所有策略只读取玩家可见信息；神秘人车费按固定期望 24 估值。三站前瞻会遮蔽隐藏车费，使用独立模拟随机数，不读取真实未来候客或真实未来随机数。

## 一、最强信号是空车冲层，不是某个人物

普通开局独立验证，每策略 300 局：

| 策略 | 平均抵达 | 中位抵达 |
| --- | ---: | ---: |
| 谨慎接客，允许后期大量空驶 | 304.32 | 311 |
| 同一经营基础，80 层后停止接客，只充电 | 298.77 | 300 |
| 平衡三人经营 | 135.02 | 131 |
| 同一谨慎策略，但自愿始终至少载一人 | 95.60 | 98 |

“始终载人”是识别空车效果的测试对照，不是建议直接加入游戏的强制规则。它会改变之后的收入、状态和候客，因此差异包含整条后续轨迹，不是某一层的局部效果。

配对比较：

- 谨慎空驶 vs 平衡三人：平均多 169.30 层；300 个同种子比较中胜率 97.67%。
- 谨慎空驶 vs 同策略持续载客：299 胜、1 平、0 负，平均多 208.73 层；配对自助抽样 95% 区间 [201.39, 215.36]。
- 谨慎空驶 vs 偏安抚六人策略：胜率 69.33%，不是每个种子都赢。因此不能称为对全部策略逐局严格支配，但优势已经足够显著，值得修正设计。

机制原因：

- 空车不承受长班疲劳。
- 空车仍可每层降低 1 躁动，直到 0。
- 存款可以在每 10 层的补给站直接换电，充电不要求继续服务乘客。
- 楼层纪录并不区分是在经营乘客，还是在空车消耗存款。

谨慎空驶策略在 80 层以后的出发中，93.58% 是空车。固定 80 层停接策略则为 99.42%。

一个完整验证样本的记录：

| 楼层 | 累计收入 | 可用金币 | 车内人数 |
| --- | ---: | ---: | ---: |
| 75 | 1607 | 748 | 5 |
| 100 | 2093 | 779 | 0 |
| 150 | 2093 | 603 | 0 |
| 200 | 2093 | 429 | 0 |
| 300 | 2093 | 79 | 0 |

这不是无限续航：空车不产生收入，每层至少耗 1 电，买 1 电花 2 金币；有限存款终会耗尽。但它允许把很长一段本应有挑战的后期变成空车按上行，绕过人物制约。

## 二、它并非在所有条件下最强

条件压力测试不是普通开局的发生概率，而是独立检验策略对状态的依赖。

- 41 层、0 金币、3 躁动：三站前瞻平均 143.38 层，谨慎空驶 141.22 层；差 2.16 的 95% 区间跨 0，不能判定谁稳定更强。
- 41 层、12/15 躁动、120 金币：三站前瞻 153.02，谨慎空驶 150.86；差异同样不明确。
- 81 层、带既有升级、150 金币：三站前瞻 178.18，谨慎空驶 157.52；平均差 20.66，95% 区间 [11.91, 31.02]，前瞻胜率 71%。

说明空驶路线依赖前期积累；在已有升级但缺少大量存款的高层局面，继续经营和预判关系有价值。这是反对“全局绝对最强”的证据，但不是可以忽略普通开局明显优势的理由。

## 三、固定人物流派没有通吃

普通开局验证中的部分均值：

| 偏好打法 | 平均抵达楼层 |
| --- | ---: |
| 恋人三人 | 131.82 |
| 警察/小偷/律师四人 | 114.44 |
| 百变人三人 | 127.64 |
| 复制人/百变人三人 | 127.33 |
| 安抚六人 | 214.57 |

这些是带偏好的完整策略，仍允许其他人物填补位置，不是强制只接指定角色。角色出现概率、路程错开、耐心、现金和站位都会限制组合。

安抚六人的均值较高，但中位仅 153、结局波动很大，不能当成稳定必赢组合。以上结果不能证明某个角色本身已经平衡，更不能排除尚未实现的更好策略。

## 四、确认的逻辑漏洞：耐心离开覆盖了爆炸

可复现、参数处于正常人物范围的场景：

- 41 层，躁动 10/15，炸弹客目的地 46 层，引信 3，耐心 6。
- 到 42 层：引信 2，耐心 4。
- 到 43 层：引信 1，耐心 2。
- 到 44 层：两者同时归零。

按“到站前引信归零立即结束”的规则，应当失败。实际结果却是炸弹客先因耐心归零离开，随后检查剩余车厢时已找不到炸弹，游戏继续，躁动只增加 2。

12 个引信/耐心同时到期的边界测试全部复现。它没有支付车费，但规避了致命风险和请离赔偿。应保留“到站当层引信归零仍安全”的现有约定，仅修正尚未到站时的事件优先级。

此前的金额、电量和躁动预测校验通过，并不能排除这类状态优先级错误。旧测试没有覆盖这个交叉边界。所有主策略保守拒绝预计提前归零的炸弹，没有有意利用此漏洞抬高成绩；不过游戏内后续随机事件仍可能触及它。

## 五、复制相关未复现的获利循环

2,000 组种子下：

- 反复移开再移回相同邻座，不会重抽复制结果。
- 换位不会白送金币或电量。
- 两个复制人互相相邻，只取本体属性，没有递归放大车费。
- 因改变邻座集合而改变属性，仍是合法的站位优化，而非同一局面无限重抽。

这只排除了已测的循环，不是对所有操作序列的数学证明。上一轮发现的“复制坏属性仍亮绿线”和“请离导致复制重排、载重反升”仍未修复。

## 建议下一轮先做什么

1. 修复炸弹的事件优先级，并把正常到站、安全暂停、耐心先到期、引信先到期、同时到期分别固定为回归测试。
2. 针对长期空驶设计限制，保留短暂空车降压/调整空间，不直接照搬本轮“始终载人”的对照规则。
3. 空驶限制需要防止“偶尔塞一个短途乘客就重置惩罚”的替代固定套路；参数必须重新跑测试，不能只凭感觉选。
4. 修复后先回放本次保存的强策略与失败样本，再换全新种子做验证。与之前发现的小偷/警察重复奖励问题分批修改，才能知道改善来自哪里。

验收应看：固定套路是否仍在多数正常开局压倒需要持续处理人物的策略；同一角色是否在不同情境下有合理优劣；操作预报是否解释清楚连锁变化。有限策略池与有限随机局数永远不能证明“绝对不存在最强打法”。
