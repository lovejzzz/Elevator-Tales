# Elevator Tales：全参数平衡测试

日期：2026-09-03。基于当前公开版本 `bc4a95c687f5362a0da21a321874317b82701438`。

## 结论

没有在本次策略池中发现一个无敌的人物组合，但发现了更重要的问题：**后期生存过度依赖舒缓系统，其他升级很难形成同等有效的路线。**

人物关系有实际收益和取舍，问题不是“协作完全没用”，而是收益常常最后又被换成舒缓卡。初始电量主要决定前期容错，不能解决后期的路线趋同。

本轮只新增测试和报告，**未修改游戏规则，未更新公开站点**。

## 测试规模与方法

| 部分 | 数量 |
| --- | ---: |
| 当前版本策略筛查 | 46 种策略 × 60 个种子 = 2,760 局 |
| 参数筛查 | 40 组规则（含基线）× 6 种策略 × 60 个种子 = 14,400 局 |
| 当前版本独立复验 | 20 种策略 × 300 个新种子 = 6,000 局 |
| 7 组候选规则复验 | 7 × 6 种策略 × 250 个新种子 = 10,500 局 |
| 容量／充满电策略复验 | 4 种策略 × 300 个新种子 = 1,200 局 |
| 前期简易操作测试 | 4 种初始电量 × 2 种开局 × 2 种策略 × 500 个种子 = 8,000 局 |
| 合计 | **42,860 次模拟：34,860 局完整流程，8,000 次前期测试** |

共有 58 种完整流程策略、42 种规则配置（40 组筛查加 2 组组合候选）。另有 6 局烟雾检查，不计入以上总数。

完整流程检查了 3,618,193 次楼层转换，未发现电量／躁动预报与结算不一致；没有一局触及 600 层模拟上限。600 层只是测试保护线，不是游戏终点。前期测试只观察到 31 层，抵达该层即停止，不算通关。

另重跑人物关系专项：231 种双人阵容、29,568 次四层短途；1,330 种三人阵容、7,980 次站位／楼层检查；126,310 次预报核对；10,000 次复制属性检查。这些受控场景不计作完整游戏局数。

使用当前真实引擎、合法上客／换位／请离、付费充电和商店。参数修改发生在隔离的测试副本中；基线引擎与线上源文件逐字一致。神秘人隐藏车费不会被决策程序提前读取；预演不读取未来候客或未来随机结果。

相同组内使用相同种子，复验种子与筛查分开。还补充了同时考虑两名候客的规划策略，避免只逐个选人而低估双人协作。价格变化时，程序使用实际充电价；容量比较额外加入“每次充满”的策略，避免只充到推荐值导致容量参数根本没被使用。

## 1. 最突出的问题：舒缓卡挤压其他升级

以下每行都是当前规则、同一批 300 个种子。“不买某张卡”是购买行为限制，不是从商店牌池删除该卡。

| 同一套稳健选人策略的购买方式 | 平均结束楼层 | 相对正常购买 |
| --- | ---: | ---: |
| 正常购买 | 114.54 | — |
| 只买舒缓系统 | **117.50** | +2.96 |
| 不买舒缓系统 | **94.29** | −20.25 |
| 所有升级都不买 | 94.19 | −20.35 |
| 不买默契契约 | 115.91 | +1.37 |
| 不买礼宾服务 | 115.89 | +1.35 |
| 不买轿厢加固 | 115.76 | +1.22 |
| 不买节能线路 | 112.02 | −2.52 |
| 不买快速电梯 | 110.94 | −3.60 |

“不买舒缓”的配对平均差为 −20.25 层，描述性 95% 自助区间为 [−21.32, −19.14]；这比其他升级的差异大得多。只买舒缓相对正常购买的区间为 [+1.64, +4.22]。

这不意味着其他卡对人类玩家没有价值：程序擅长提前拒载、请离和规避耐心损失。它说明在这种高效操作下，额外耐心、更多载重和更多金币的收益，没有充分转化为后期生存优势。固定的购买评分也可能花掉本应保留的金币，不能把“不买更好”直接解读为该卡必须删除。

最强这组策略平均乘坐人数为 3.69，并不是全程只带两人；它前期接客、后期收缩，并每局平均买 5.28 次舒缓卡。其 300 局都因躁动结束。在它产生的原始正向躁动中，疲劳和拥挤合计占 97.3%。这说明它成功规避了多数人物负面效果后，主要在对抗随楼层增加的固定压力；这个比例不是所有人类玩家的比例。

其他较强策略：提前预演／休整 115.99 层、少载客与休整交替 115.42 层。没有证据可宣布某一种策略在所有局面中绝对占优。

## 2. 初始电量：前期很敏感，高手后期不敏感

容量固定 24。下表是“按出现顺序最多接两人、不换位、不买升级、先充电”的简易策略，每格 500 局。不是实测新手胜率。

| 初始电量 | 随机开局：到达 20 层 | 随机开局：到达 31 层 | 教学恋人开局：到达 31 层 |
| --- | ---: | ---: | ---: |
| 18 | 38.4% | 27.4% | 90.6% |
| **20（当前）** | **55.0%** | **37.6%** | **96.4%** |
| 22 | 68.4% | 53.8% | 97.8% |
| 24 | 83.4% | 69.0% | 99.4% |

18 → 20 → 22 有明确的早期容错差异。随机开局只接两人时，前十层平均赚 32.97 金币，充完电后余额很少，容易在第二段断电。教学给出的恋人组合明显缓解这个问题。因此不能只测固定的第一班，再认定随机开局对新手也同样轻松。

相反，高手策略筛查中，20 → 22 后六种策略平均层数变化仅 +0.65；20 → 24 为 +0.53。这些是探索结果，不是人类难度估计。

**建议：当前保留 20／24。若目标是提高新手容错，可单独考虑初始 22，但不要期待它解决后期平衡。**

容量 24 → 28 的复验还加入了“充满电”策略：两种对应打法分别只变化 +0.18、−0.15 层，没有稳定的改善。推荐充电策略完全相同，是因为通常只充到 22；不能据此单独宣布容量无用。

## 3. 最值得继续验证的规则：让四人组合有空间

把拥挤开始人数从 4 改为 5；六人仍每层 +2，五人仍 +1，三至四人不加拥挤，两人及以下仍 −1。只改这一项。

下表使用同一批 **250 个复验种子**，所以基线数字与上面 300 局表有轻微差别。

| 策略 | 当前 4 人开始拥挤 | 5 人开始拥挤 | 平均变化 |
| --- | ---: | ---: | ---: |
| 警察／小偷偏好 | 90.93 | 104.11 | **+13.18** |
| 音乐家／护士偏好 | 103.21 | 107.07 | +3.86 |
| 稳健灵活选人 | 114.66 | 118.64 | +3.98 |
| 稳健选人、只买舒缓 | 117.70 | 123.33 | +5.63 |
| 少载客／休整交替 | 115.56 | 117.20 | +1.64 |
| 最多三人 | 96.76 | 96.76 | 0 |

警察／小偷策略的配对变化区间为 [+11.34, +15.10]。它与“只买舒缓”的平均差距从 26.77 缩到 19.22 层，但并没有追平，也没有解决舒缓卡依赖。

**这是候选方向，不是已经证明平衡的发布版本。** 人数放宽会同时强化音乐家和多角色组合，仍需更强的多人阵容／重复安抚角色专项测试。

## 4. 哪些直觉上的修改没有解决问题

- **协作基础奖励 3 → 5：**六种复验策略的平均变化都在约 −1～+1 层；各自区间都跨过 0。警察／小偷只 +0.06 层。收益更高不等于能承受更多人带来的躁动。
- **协作 +5 再加四人免拥挤：**警察／小偷到 103.50 层，反而没有超过只改拥挤的 104.11 层。暂时没有理由两项一起改。
- **舒缓立即减躁 6 → 4：**只买舒缓的策略下降 3.50 层；其他几条路线也下降，未形成清晰的新路线。单纯削弱生存手段主要让全局更难。
- **充电单价 2 → 3：**最多三人策略下降 17.21 层，稳健灵活策略基本不变。它更像惩罚周转不够熟练的玩家，不利于缩小策略差距。
- **疲劳每 30 层增加 → 每 35 层：**六种策略普遍多走约 11～15 层。它能延长一局，但强弱排序大体保留，不能把“层数变高”当成“玩法更丰富”。

## 5. 全参数筛查覆盖

以下是 60 个种子、六种固定策略的单变量探索；未单独复验的项不作为定案依据。

| 参数 | 测过的范围 | 主要观察 |
| --- | --- | --- |
| 初始电量 | 18 / 20 / 22 / 24 | 主要影响早期现金／充电容错 |
| 电池容量 | 20 / 24 / 28 | 当前十层补给节奏下，增加容量的价值小 |
| 躁动上限 | 12 / 15 / 18 | 改善或收紧容错，没改核心排序 |
| 疲劳阶梯 | 25 / 30 / 35 层 | 影响整局长度最明显的参数之一 |
| 耐心加速阈值 | 上限 50% / 约 67% / 80% | 对擅长拒载和请离的程序影响较小 |
| 宽松轿厢舒缓 | 每层 −1 / 取消 | 取消后六策略平均少约 22.71 层，并非更丰富 |
| 拥挤起点 | 4 / 5 人 | 更有利于多人组合，值得重点继续测 |
| 基础车费 | 85% / 100% / 115%，逐项取整 | 包含随机人物车费，不改途中收益或技能倍率 |
| 每电充电价格 | 1 / 2 / 3 金币 | 涨价明显伤害普通周转路线 |

| 每十层商店涨价 | 8 / 12 / 16 金币 | 六策略平均变化约 +2.06 / 0 / −3.59 层 |
| 舒缓基础价格 | 25 / 35 / 45 金币 | 六策略平均变化约 +1.16 / 0 / −1.46 层 |
| 舒缓增加上限 | 2 / 3 / 4 | 影响生存，但仍围绕舒缓投资 |
| 舒缓立即减躁 | 4 / 6 / 8 | 单独削弱没有明显增加路线多样性 |

| 初始耐心 | 原值 −1 / 原值 / 原值 +1 | 当前高手程序影响小，不能外推新手 |

| 炸弹初始引信 | 2–5 / 3–6 / 4–7 | 程序主动拒绝无法送达的炸弹，不能拿低死亡数推断人类难度 |

## 6. 人物关系的取舍仍然成立

受控、固定路程的双人测试（不是整局排名）：

- 恋人相邻，四层短途比同样两人分开多赚 26 金币。组合收益很强，但依赖候客、站位及同伴在场时间。
- 教练＋名人：相邻多赚 24 金币，同时多 2 躁动，是明确的风险收益交换。
- 小偷＋警察，同路两站时相邻共赚 26、分开 19；同路六站时相邻 30、分开 31，但相邻少 3 躁动。短途控制能同时占优，长途则有少赚钱换稳定的取舍。
- 儿童仍是需要关注的低回报角色：标准四站、无人照顾的案例无法收取车费；有护士相邻才收 8 金币。相同检查下通勤者可收 7 金币。这个单一案例不足以定案，但说明儿童的回报／依赖关系值得下一轮单独审视。
- 复制人仍可能把好属性换坏；失去零载重来源，甚至可能让车厢变重。绿线表示发生连接，不等于纯收益。这是已有机制／表达风险，不是这次改出来的新问题。
- 警察先下车后，炸弹可能变得无法送达；双警察不叠加暂停、双教练不叠加倍率、同层恋人双方结算均通过回归检查。

## 建议的下一步

1. **保留基线：20／24 电、2 金币／电、基础协作 +3、休整 3 次。** 初始 22 可以作为前期容错候选，而不是后期平衡修复。
2. **下一轮只重点推进“四人免拥挤”候选。** 测重复音乐家／护士、多组协作、不同载重组合，并用更广的策略池重新竞争；不要同时涨全部车费或协作奖。
3. **重新审视升级的生存价值和机会成本。** 默契、礼宾、加固应有各自可成立的路线；当前数据不支持仅靠削弱舒缓来解决。具体新机制尚未实现或验证。
4. **关注教学与随机重开的落差。** 更清楚地展示下一段充电预算，可能比永久抬高初始电量更精准；这也是尚未实现的建议。

## 局限与复现

这是程序策略测试，不是人类可玩性或上瘾性验证。有限策略池不能证明全局不存在最优打法。更大的搜索范围也不保证更聪明：此次双人规划仍使用同一套短期评分，它没有超过原来的稳健策略，不能据此断言协作规划没用。

除充电预算、休整储量和隐藏车费估计外，多数启发式权重没有为每一组参数重新优化；参数效果包含该固定决策规则的行为变化。部分曲线不单调是可能的，不能把小幅波动解读为必然因果改善。

区间使用配对自助抽样，未对多重比较校正，均按描述性结果报告。筛查与策略发现使用相同种子；复验使用另一组种子，不能把筛查和基线当独立样本相加来宣称更高精度。楼层种子统一，但恋人呼唤及随机事件会依赖当前状态，并不保证不同策略看到完全相同的候客序列。

复现入口：`scripts/audit-parameters.ts`、`scripts/audit-onboarding.ts`、`scripts/summarize-parameters.ts`。`reproduction.json` 保存每组实际种子、参数、局数、策略和源文件哈希；`generated-sources/` 保存真正运行过的引擎、人物属性模块和策略程序文本，其余支持模块来自上方源代码版本。新测试可用 `ELEVATOR_AUDIT_OUTPUT` 指定新目录，避免覆盖本次结果。

数据：`analysis.json` 为汇总；`baseline/`、`screen/`、`holdout/` 保存逐局结束楼层及累计事件；`onboarding.json` 为前期实验；`relationships.json` 为人物关系专项。线上源文件未改变，测试产物不被游戏导入。
